## 📌 Descripción

**MinBox School System** es una plataforma desarrollada en **C# (.NET)** que permite la gestión integral de instituciones educativas.

El sistema está diseñado para administrar **estudiantes, docentes, materias, calificaciones y procesos académicos**, facilitando el control y la organización escolar en una sola aplicación.

---

## 🚀 Características

* 👨‍🎓 Gestión de estudiantes
* 👨‍🏫 Administración de docentes
* 📚 Control de materias y cursos
* 📝 Registro de calificaciones
* 📅 Control de asistencia
* 📊 Reportes académicos
* 🔐 Sistema de autenticación
* 🧾 Historial académico por alumno

## ⚙️ Instalación

### Requisitos

* .NET SDK (6 o superior)
* SQL Server o SQLite

### Pasos

```bash id="mnb123"
# Clonar repositorio
git clone https://github.com/isairey/SistemaEscolar-Mindbox.git

# Entrar al proyecto
cd SistemaEscolar-Mindbox

# Restaurar dependencias
dotnet restore

# Ejecutar migraciones
dotnet ef database update

# Ejecutar aplicación
dotnet run
```
